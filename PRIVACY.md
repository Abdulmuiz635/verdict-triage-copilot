# Privacy Policy — Verdict

_Last updated: 6 November 2026_

Verdict is a vulnerability-triage app for Atlassian Jira, built on Atlassian Forge. This policy explains what the app accesses, what it stores, and what it sends to external services.

## Personal data

Verdict does **not** store personal data. It does not copy, cache, or persist any user's name, email, account ID, or other personal information in its own storage.

## What the app accesses

To triage a security finding, Verdict reads the Jira issue and its fields (summary, description, and the custom fields Severity, CVSS, CVE ID, and Affected service). It writes back to the issue: a priority, a comment, issue links, an assignee, and a status transition. These reads and writes happen through Atlassian's APIs and stay within your Atlassian site.

## What the app stores

Verdict keeps a small per-issue audit log in Forge storage (Forge KVS) so each action can be traced. Each entry contains only non-personal triage metadata: the action taken, the resulting priority, the CVE id, severity, CVSS, the affected service name, whether the CVE is known-exploited, a timestamp, and whether the trigger was automatic or manual. No names, emails, or account identifiers are stored. Entries are capped per issue and are removed when the app is uninstalled.

## External services

To enrich a finding, Verdict sends only a CVE identifier, or a service (repository) name, to the following read-only sources. No personal data and no issue content are sent.

- **NVD** (services.nvd.nist.gov) — CVE description and CVSS
- **CISA KEV** (www.cisa.gov) — known-exploited status
- **EPSS** (api.first.org) — exploitation probability
- **Bitbucket** (api.bitbucket.org) — reads a repository's CODEOWNERS file to determine the service owner

Narratives shown to the user are generated by Atlassian Intelligence through the Forge LLMs API, using only the grounded facts above. No external AI model or key is used.

## Data sharing

Verdict does not sell or share any data. It has no analytics and no third-party tracking.
